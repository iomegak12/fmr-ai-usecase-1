Kalash API Gateway

Savings Goal Planner, Release 1. Single public origin for the back-end services.

APIs

/api/v1/goalsGoal Service: goals, progress and insights
/api/v1/transactionsTransaction Service: deposits, withdrawals and history

Rate limited per client IP. Responses carry X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset; over the limit you get HTTP 429 (COMMON-429) with Retry-After.
